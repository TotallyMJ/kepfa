# Kepfa · Keep the sky.

ต้นแบบเว็บแอป (mobile-first) สำหรับเก็บภาพท้องฟ้า ถ่ายฟ้าผ่านกรอบโหลแยม พับรูปลงโหล ปิดฝา แล้ววางไว้บนชั้น หน้าตาแอปเป็นสไตล์ editorial และใช้ภาษาอังกฤษ

ลองได้ที่ https://totallymj.github.io/kepfa/

## วิธีรันในเครื่อง

```bash
npm start
```

แล้วเปิด http://localhost:5173

- ไม่ต้องติดตั้ง dependency ใช้แค่ Node (`server.js` เป็น static server ตัวเล็ก)
- กล้องในหน้าเว็บต้องใช้ https หรือ localhost ถ้าเปิดผ่าน http บนมือถือ แอปจะสลับเป็นปุ่ม "Take a photo" ที่เปิดแอปกล้องของเครื่องแทน
- เปิดครั้งแรกจะมีฟ้าตัวอย่างวางไว้บนชั้น กด "Clear samples" เพื่อเริ่มเก็บฟ้าของตัวเอง

## ฟีเจอร์ (เฟส 1–2)

| ส่วน | ทำอะไรได้ |
|---|---|
| โหล | ทุกที่ที่มีรูปจะอยู่ในโหลแยมฝาเกลียวทรงเดียวกัน (ขณะถ่าย, ชั้นวาง, รายละเอียด, รูปแชร์) วาดจาก `jarShape()` ที่เดียว |
| เก็บฟ้า | ปุ่มกล้องกลางแถบล่าง → จอกล้องมองผ่านโหล หรือเลือกรูปจากคลังภาพ → ดึง palette 3–5 สี → ใส่ Note และ Place (ไม่บังคับ) → กด Keep แล้วรูปพับสามเหลี่ยม 3 ทบ พลิกตัวลงโหลพร้อมแสงตามหลังและวงแสงที่ปากโหล ฝาลงมาแล้วบิด "แกร๊ก" |
| Shelf (หน้าแรก) | หัวแบบนิตยสาร, แถบ golden hour, Sky dare (โจทย์รายวัน 30 ข้อ เปลี่ยนตอนเที่ยงคืน), วันนี้ในอดีต (ปีก่อน/เดือนก่อน/สัปดาห์ก่อน), ชั้นวางหนึ่งโหลต่อหนึ่งฟ้า |
| เปิดดูฟ้า | บิดฝา "แกร๊ก" แล้วยกออก กระดาษพลิกตัวลอยขึ้นจากโหลแล้วคลี่ออกทีละทบ กด "Put it back" เพื่อพับกลับลงโหลแล้วปิดหน้าต่าง |
| ลายมือ | โจทย์และบันทึกภาษาอังกฤษใช้ Reenie Beanie ส่วนข้อความภาษาไทยใช้ฟอนต์ปกติ |
| Months | หนึ่งโหลต่อหนึ่งเดือน มีชั้นสีของทุกฟ้าในเดือนนั้น แตะเข้าไปดูสถิติ สีประจำเดือน "Shake" สุ่มความทรงจำ |
| Share to story | รูป 1080×1920 บนกระดาษ: quote สุ่ม 30 แบบใต้ชื่อ (ใช้ครบทุกอันก่อนวนซ้ำ), ท้ายรูป "kepfa · start your own collection", ฟ้าเดี่ยว (โหล + บันทึกลายมือ + วันที่-เวลา + palette), โหลรายเดือน, ชั้นวางทั้งปี |
| Golden hour | คำนวณในเครื่องจากพิกัด (ค่าเริ่มต้นกรุงเทพฯ) กด "Bangkok" เพื่อใช้ตำแหน่งจริง เก็บพิกัดแบบปัดเศษไว้ในเครื่องเท่านั้น |
| ความเป็นส่วนตัว | ข้อมูลอยู่ในเครื่องเท่านั้น (IndexedDB) ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ป้ายสถานที่ในรูปแชร์ปิดไว้เป็นค่าเริ่มต้นทุกครั้ง และรูปแชร์ถูกวาดใหม่ จึงไม่มีข้อมูล GPS ติดไป |

## โครงสร้าง

```
index.html          โครงหน้า + overlay (กล้อง, รายละเอียด, แชร์)
css/style.css       design tokens (Kinfolk), layout, dark mode
js/strings.js       ข้อความทั้งหมดในแอป + รูปแบบวันที่ (เพิ่มภาษาอื่นได้ที่ไฟล์นี้)
js/app.js           routing (#/, #/months, #/month/YYYY-MM), หน้าจอทั้งหมด, flow เก็บฟ้า, ข้อมูลตัวอย่าง
js/jar.js           โหล: เรขาคณิต, SVG สำหรับหน้าจอ, canvas สำหรับรูปแชร์, ชั้นสีรายเดือน
js/fold.js          แอนิเมชันพับรูปลงโหลและคลี่ออก (3 ทบ, พลิกตัว, แสง, บิดฝา)
js/sound.js         เสียงกริ๊ง, เสียงวูบ, เสียงแกร๊กของฝา (WebAudio ไม่มีไฟล์เสียง)
js/sun.js           คำนวณเวลาพระอาทิตย์ขึ้น-ตก และ golden hour
js/sky.js           ดึง palette, ย่อรูป, วาดฟ้าตัวอย่าง
js/story.js         สร้างรูปสตอรี่ 1080×1920 และแชร์/บันทึก
js/store.js         IndexedDB
server.js           static server สำหรับ dev
```

## แผนถัดไป

- **เฟส 3:** หน้าสรุปเดือน / ปี
- **เฟส 4 (ต้องมีเซิร์ฟเวอร์):** โหลของขวัญ, ฟ้าเดียวกัน

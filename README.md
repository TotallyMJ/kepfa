# Kepfa · Keep the sky.

ต้นแบบเว็บแอป (mobile-first) สำหรับเก็บภาพท้องฟ้า ถ่ายฟ้าผ่านกรอบโหลแยม พับรูปลงโหล ปิดฝา แล้ววางไว้บนชั้น หน้าตาแอปเป็นสไตล์ editorial และใช้ภาษาอังกฤษ

ลองได้ที่ https://totallymj.github.io/kepfa/

## วิธีรันในเครื่อง

```bash
npm start
```

แล้วเปิด http://localhost:5173

- ไม่ต้องติดตั้ง dependency ใช้แค่ Node (`server.js` เป็น static server ตัวเล็ก)
- กล้องในหน้าเว็บต้องใช้ https หรือ localhost ถ้าเปิดผ่าน http บนมือถือ แอปจะสลับเป็นปุ่ม "Take a photo" ที่เปิดแอปกล้องของเครื่องแทน
- เปิดครั้งแรกจะมีฟ้าตัวอย่างวางไว้บนชั้น กด "Clear samples" เพื่อเริ่มเก็บฟ้าของตัวเอง

## ฟีเจอร์ (เฟส 1–2)

| ส่วน | ทำอะไรได้ |
|---|---|
| โหล | ภาพถ่ายโหลแยมฝาทองเหลือง (`assets/jar.jpg` สร้างด้วย Canva AI) ตอนเปิดแอปจะแยกเป็นชั้นกระจกโปร่งใสกับฝา แล้ววางฟ้าไว้ข้างใน ใช้ทุกจุด (ขณะถ่าย, ชั้นวาง, รายละเอียด, รูปแชร์) โหมดมืดใช้ชั้นกระจกสีสว่าง |
| เก็บฟ้า | ถ่ายสดเท่านั้น (ไม่มีคลังภาพ ถ้ากล้องในเว็บเปิดไม่ได้จะมีปุ่ม "Take a photo" ที่เปิดแอปกล้องของเครื่อง) → ตอนกดถ่ายเก็บเฉพาะส่วนที่อยู่ในโหล → "Tell this sky something", Where, เวลาที่ถ่ายจริงแสดงเป็นตัวหนังสือ (แก้ไม่ได้) และแถวติ๊ก "Kept for today" (ติ๊กไว้ให้ถ้ากดมาจาก Look up) → ปุ่ม Keep ติดอยู่ล่างจอ กดแล้วรูปพับสามเหลี่ยม 3 ทบ พลิกตัวลงโหล ฝาลงมาแล้วบิด "แกร๊ก" |
| My Skies (หน้าแรก) | หัวแบบนิตยสาร, แถบ golden hour, กล่อง "Today's sky challenge" กระดาษฉีกแปะเทปบนแผ่นสีฟ้าที่เปลี่ยนตามเวลาจริง (กลางวันฟ้าใส, golden hour ส้มพีช, กลางคืนน้ำเงินเข้ม) พร้อมปุ่ม "Look up and keep it" (โจทย์ 30 ข้อที่ใช้ได้ทุกสภาพอากาศ เปลี่ยนตอนเที่ยงคืน), ลิงก์ไปดู #Kepfa24Oct ใน Instagram, ชาเลนจ์ 30 skies, วันนี้ในอดีต, โหลของเดือนนี้เท่านั้น (เดือนอื่นกด "See every month ›" ไปหน้า Months) |
| เปิดดูฟ้า | บิดฝา กระดาษคลี่ออกจากโหล แล้วเด้งเป็นโพลารอยด์มุมมนลอยทับโหล ฉากหลังเบลอและมืดลง (เต็มรูปแบบครั้งแรก ครั้งต่อไปแบบสั้น แตะที่ไหนก็ได้เพื่อข้าม) ข้อความ วันที่ และสถานที่อยู่ที่ขอบล่างโพลารอยด์ แตะข้อความเพื่อแก้ตรงนั้นได้เลย (Done หรือปุ่ม ✓ บนคีย์บอร์ดบันทึก) ✕ ที่มุมรูปหรือลากลงเพื่อเก็บกลับเข้าโหล ปัดซ้าย-ขวาเพื่อดูฟ้าอื่น (คีย์บอร์ดใช้ลูกศร) ปุ่ม "Share this sky" อยู่กลางใต้รูป |
| ลบฟ้า | กดค้างที่โหลบนหน้าแรกหรือหน้ารายเดือน โหลจะสั่นพร้อม ✕ วงกลมที่มุมขวาบน (เหมือนลบแอปบนมือถือ) แตะ ✕ แล้วถามยืนยันกลางจอ แตะที่อื่นหรือเลื่อนจอเพื่อยกเลิก ครั้งแรกที่ปิดโหลจะมีคำใบ้ "Hold a jar to delete it" ขึ้นครั้งเดียว |
| Motion | ใช้จังหวะชุดเดียวทั้งแอป (เข้า/ออก/เด้ง) ตั้งไว้เป็นค่ากลางใน `css/style.css` และ `MOTION` ใน `js/fold.js` ปุ่มยุบแล้วเด้งกลับเวลากด ของที่โผล่ขึ้นมาทยอยตามกันทีละชิ้น เคารพการตั้งค่า "ลดการเคลื่อนไหว" ของเครื่อง |
| กระดาษกับเทป | ภาพจริงจาก Canva AI ตัดพื้นหลังแล้วเก็บเป็น `assets/paper.webp`, `note.webp`, `tape.webp` กระดาษยืดตามความยาวข้อความโดยขอบไม่เบี้ยว (9-slice) ใช้ที่กล่องโจทย์และรูปแชร์ สคริปต์ตัดภาพอยู่ใน `_mockups/textures.py` (ไม่ขึ้น git) |
| ลายมือ | บันทึกภาษาอังกฤษใช้ Reenie Beanie ส่วนภาษาไทยใช้ฟอนต์ปกติ โจทย์ใช้ตัว serif เพื่อให้อ่านง่าย |
| Months | หนึ่งโหลต่อหนึ่งเดือน มีชั้นสีของทุกฟ้าในเดือนนั้น แตะเข้าไปดูสถิติ สีประจำเดือน "Shake" สุ่มความทรงจำ |
| Share to story | รูป 1080×1920 บนกระดาษ: quote สุ่ม 30 แบบใต้ชื่อ (ใช้ครบทุกอันก่อนวนซ้ำ), ท้ายรูป "kepfa · start your own sky collection", ฟ้าเดี่ยว (โหล + บันทึกลายมือบนกระดาษโน้ต + วันที่-เวลา + palette), "Share October's jar" (ชั้นวางของเดือนนั้น ฟ้าจริงในโหลทุกใบพร้อมวันที่ ขนาดโหลปรับตามจำนวน), "Share my year in skies" (โหลรายเดือน 12 ใบ) ฟ้าที่ติ๊ก "Kept for today" จะมีกระดาษโจทย์แปะเทปพร้อม `#kepfachallenge #Kepfa24Oct` แทน palette และตอนกด Share/Save จะคัดลอกแคปชันพร้อมแฮชแท็กให้ |
| Golden hour | คำนวณในเครื่องจากพิกัด (ค่าเริ่มต้นกรุงเทพฯ) กด "Bangkok" เพื่อใช้ตำแหน่งจริง เก็บพิกัดแบบปัดเศษไว้ในเครื่องเท่านั้น |
| ความเป็นส่วนตัว | ข้อมูลอยู่ในเครื่องเท่านั้น (IndexedDB) ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ป้ายสถานที่ในรูปแชร์ปิดไว้เป็นค่าเริ่มต้นทุกครั้ง และรูปแชร์ถูกวาดใหม่ จึงไม่มีข้อมูล GPS ติดไป |

## โครงสร้าง

```
index.html          โครงหน้า + overlay (กล้อง, รายละเอียด, แชร์)
css/style.css       design tokens (Kinfolk), layout, dark mode
js/strings.js       ข้อความทั้งหมดในแอป + รูปแบบวันที่ (เพิ่มภาษาอื่นได้ที่ไฟล์นี้)
js/app.js           routing (#/, #/months, #/month/YYYY-MM), หน้าจอทั้งหมด, flow เก็บฟ้า, ข้อมูลตัวอย่าง
js/jar.js           โหล: เรขาคณิต, SVG สำหรับหน้าจอ, canvas สำหรับรูปแชร์, ชั้นสีรายเดือน
js/fold.js          แอนิเมชันพับรูปลงโหลและคลี่ออก (3 ทบ, พลิกตัว, แสง, บิดฝา)
js/sound.js         เสียงกริ๊ง, เสียงวูบ, เสียงแกร๊กของฝา (WebAudio ไม่มีไฟล์เสียง)
js/sun.js           คำนวณเวลาพระอาทิตย์ขึ้น-ตก และ golden hour
js/sky.js           ดึง palette, ย่อรูป, วาดฟ้าตัวอย่าง
js/story.js         สร้างรูปสตอรี่ 1080×1920 และแชร์/บันทึก
js/store.js         IndexedDB
server.js           static server สำหรับ dev
```

## แผนถัดไป

- **เฟส 3:** หน้าสรุปเดือน / ปี
- **เฟส 4 (ต้องมีเซิร์ฟเวอร์):** โหลของขวัญ, ฟ้าเดียวกัน

# Kepfa · Keep the sky.

ต้นแบบเว็บแอป (mobile-first) สำหรับเก็บภาพท้องฟ้า ถ่ายฟ้าผ่านกรอบโหลแยม พับรูปลงโหล ปิดฝา แล้ววางไว้บนชั้น หน้าตาแอปเป็นสไตล์ editorial และใช้ภาษาอังกฤษ

ลองได้ที่ https://totallymj.github.io/kepfa/

## วิธีรันในเครื่อง

```bash
npm start
```

แล้วเปิด http://localhost:5173

- ไม่ต้องติดตั้ง dependency ใช้แค่ Node (`server.js` เป็น static server ตัวเล็ก)
- กล้องในหน้าเว็บต้องใช้ https หรือ localhost ถ้าเปิดผ่าน http บนมือถือ แอปจะสลับเป็นปุ่ม "Choose from your photos" แทน
- เปิดครั้งแรกจะมีฟ้าตัวอย่าง 8 ใบ (รูปฟ้าจริงใน `assets/sky/` ย่อแล้วและลบข้อมูล GPS ออก) 6 ใบในเดือนนี้ รวมหนึ่งใบเมื่อ 7 วันก่อนให้ "A week ago" มีอะไรโชว์ และ 2 ใบในเดือนก่อน กด "Clear samples" เพื่อเริ่มเก็บฟ้าของตัวเอง ต้นฉบับอยู่ใน `assets/samples/` (ไม่ขึ้น git) ย่อด้วย `_mockups/samples.py`

## ฟีเจอร์ (เฟส 1–2)

| ส่วน | ทำอะไรได้ |
|---|---|
| โหล | ภาพถ่ายโหลแยมฝาทองเหลือง (`assets/jar.jpg` สร้างด้วย Canva AI) ตอนเปิดแอปจะแยกเป็นชั้นกระจกโปร่งใสกับฝา แล้ววางฟ้าไว้ข้างใน ใช้ทุกจุด (ขณะถ่าย, ชั้นวาง, รายละเอียด, รูปแชร์) โหมดมืดใช้ชั้นกระจกสีสว่าง |
| เก็บฟ้า | ถ่ายผ่านกรอบโหล (เก็บเฉพาะส่วนที่อยู่ในโหล) หรือกด "From your photos" เลือกรูปจากคลังแล้วลาก/บีบ (หรือหมุนล้อเมาส์) จัดฟ้าให้พอดีโหลเอง ตัดด้วยสูตรเดียวกับกล้อง รูปจากคลังอ่านวันที่ถ่ายจาก EXIF ก่อนตัด: ถ่ายวันนี้นับชาเลนจ์ได้, ถ่ายวันอื่นไปอยู่เดือนที่ถ่ายจริงและไม่นับชาเลนจ์, ไม่มีวันที่ให้เลือกเอง ("When was this?") ไม่เก็บ GPS เพราะรูปถูกวาดใหม่ ถ่ายหรือกด "Use this" แล้วรูปพับสามเหลี่ยมลงโหลที่ยังเปิดอยู่ทันที จากนั้นเขียนบนกระดาษโน้ตฉีก (สีกระดาษ 5 แบบ แต่ละฟ้าได้สีประจำตัว): "Tell this sky something", Where และเวลา ใต้กระดาษเป็นการ์ด "Count it for today's challenge" กด "Close the lid" แล้วบันทึกก่อน จากนั้นกระดาษม้วนเป็นแท่ง ผูกโบว์เชือกป่าน ถูกโยนลงโหลตามแรงโน้มถ่วง เด้งที่ก้นโหล แล้วฝาตกลงมา บิด "แกร๊ก" ครั้งเดียว (มือถือ Android สั่นเบาๆ) ถ้าไม่มีข้อความฝาก็ปิดเลย กด Cancel/Retake ก่อนปิดฝาจะไม่บันทึกอะไร |
| My Skies (หน้าแรก) | หัวแบบนิตยสาร, แถบ golden hour, กล่อง "Daily sky challenge" แบบคอลลาจ: แผ่นฟ้าฉีกขอบบนเอียงขวาซึ่งสีเปลี่ยนตามเวลาจริง (กลางวันฟ้าใส, golden hour ส้มพีช, กลางคืนน้ำเงินเข้มมีดาว) กับกระดาษโจทย์ "Look for" แปะเทปเอียงซ้าย พร้อมปุ่ม "Catch today's sky" (โจทย์ 30 ข้อที่ใช้ได้ทุกสภาพอากาศ เปลี่ยนตอนเที่ยงคืน), "See who caught it ↗" ไปดู #Kepfa24Oct ใน Instagram, "Your 30-day challenge" กับ "1 of 30 days", วันนี้ในอดีต, โหลของเดือนนี้เท่านั้น (เดือนอื่นกด "See every month ›" ไปหน้า Months) |
| เปิดดูฟ้า | บิดฝา กระดาษคลี่ออกจากโหล แล้วเด้งเป็นโพลารอยด์มุมมนลอยทับโหล ฉากหลังเบลอและมืดลง (เต็มรูปแบบครั้งแรก ครั้งต่อไปแบบสั้น แตะที่ไหนก็ได้เพื่อข้าม) วันที่และสถานที่อยู่ที่ขอบล่างโพลารอยด์ ส่วนโน้ตเป็นม้วนกระดาษที่เด้งออกจากโหลตามมา แก้โบว์แล้วคลี่เป็นกระดาษโน้ตสีเดิมใต้รูป (ฟ้าที่ไม่มีโน้ตจะมี "Write on this one" บนขอบรูปแทน) แตะกระดาษเพื่อแก้ข้อความและสถานที่ตรงนั้นได้เลย (Done หรือปุ่ม ✓ บนคีย์บอร์ดบันทึก) ✕ ที่มุมรูปหรือลากลงเพื่อเก็บกลับเข้าโหล โดยรูปพับลงก่อน กระดาษม้วนตามลงไป แล้วฝาปิด ปัดซ้าย-ขวาเพื่อดูฟ้าอื่น (คีย์บอร์ดใช้ลูกศร) ปุ่ม "Share this sky" อยู่กลางใต้รูป |
| ลบฟ้า | กดค้างที่โหลบนหน้าแรกหรือหน้ารายเดือน โหลจะสั่นพร้อม ✕ วงกลมที่มุมขวาบน (เหมือนลบแอปบนมือถือ) แตะ ✕ แล้วถามยืนยันกลางจอ แตะที่อื่นหรือเลื่อนจอเพื่อยกเลิก ครั้งแรกที่ปิดโหลจะมีคำใบ้ "Hold a jar to delete it" ขึ้นครั้งเดียว |
| Motion | ใช้จังหวะชุดเดียวทั้งแอป (เข้า/ออก/เด้ง) ตั้งไว้เป็นค่ากลางใน `css/style.css` และ `MOTION` ใน `js/fold.js` ปุ่มยุบแล้วเด้งกลับเวลากด ของที่โผล่ขึ้นมาทยอยตามกันทีละชิ้น เคารพการตั้งค่า "ลดการเคลื่อนไหว" ของเครื่อง |
| กระดาษกับเทป | ภาพจริงจาก Canva AI ตัดพื้นหลังแล้วเก็บเป็น `assets/paper.webp`, `note.webp`, `tape.webp` กระดาษยืดตามความยาวข้อความโดยขอบไม่เบี้ยว (9-slice) ใช้ที่กล่องโจทย์และรูปแชร์ สคริปต์ตัดภาพอยู่ใน `_mockups/textures.py` (ไม่ขึ้น git) |
| ลายมือ | บันทึกภาษาอังกฤษใช้ Reenie Beanie ส่วนภาษาไทยใช้ฟอนต์ปกติ โจทย์ใช้ตัว serif เพื่อให้อ่านง่าย |
| Months | หนึ่งโหลต่อหนึ่งเดือน มีชั้นสีของทุกฟ้าในเดือนนั้น แตะเข้าไปดูสถิติ สีประจำเดือน "Shake for a memory" สุ่มความทรงจำ |
| Share to story | รูป 1080×1920 บนกระดาษ: quote สุ่ม 30 แบบใต้ชื่อ (ใช้ครบทุกอันก่อนวนซ้ำ), ท้ายรูป "kepfa · start your own sky collection", ฟ้าเดี่ยว (โหล + บันทึกลายมือบนกระดาษโน้ต + วันที่-เวลา + palette), "Share October's jar" (ชั้นวางของเดือนนั้น ฟ้าจริงในโหลทุกใบพร้อมวันที่ ขนาดโหลปรับตามจำนวน), "Share my year in skies" (โหลรายเดือน 12 ใบ) ฟ้าที่ติ๊ก "Count it for today's challenge" จะมีกระดาษโจทย์แปะเทปพร้อม `#kepfachallenge #Kepfa24Oct` แทน palette และตอนกด Share/Save จะคัดลอกแคปชันพร้อมแฮชแท็กให้ |
| Golden hour | คำนวณในเครื่องจากพิกัด ค่าเริ่มต้นเดาเมืองจากเขตเวลาของเครื่อง (ตาราง 50 เมืองใน `js/sun.js` เขตเวลาอื่นใช้ชื่อเขตและลองจิจูดจาก UTC offset) แสดงเป็น "⌖ Bangkok · not here?" แตะเพื่อใช้ตำแหน่งจริง แล้วเปลี่ยนเป็น "⌖ near you" เก็บพิกัดแบบปัดเศษไว้ในเครื่องเท่านั้น |
| ความเป็นส่วนตัว | ข้อมูลอยู่ในเครื่องเท่านั้น (IndexedDB) ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ป้ายสถานที่ในรูปแชร์ (ป้ายกระดาษมะนิลาลายเมฆจิ๋ว ผูกด้ายแดงรอบคอโหล เขียนชื่อสถานที่ด้วยลายมือ) ปิดไว้เป็นค่าเริ่มต้นทุกครั้ง และรูปแชร์ถูกวาดใหม่ จึงไม่มีข้อมูล GPS ติดไป |

## โครงสร้าง

```
index.html          โครงหน้า + overlay (กล้อง, รายละเอียด, แชร์)
css/style.css       design tokens (Kinfolk), layout, dark mode
js/strings.js       ข้อความทั้งหมดในแอป + รูปแบบวันที่ (เพิ่มภาษาอื่นได้ที่ไฟล์นี้)
js/app.js           routing (#/, #/months, #/month/YYYY-MM), หน้าจอทั้งหมด, flow เก็บฟ้า, ข้อมูลตัวอย่าง
js/jar.js           โหล: เรขาคณิต, SVG สำหรับหน้าจอ, canvas สำหรับรูปแชร์, ชั้นสีรายเดือน
js/fold.js          แอนิเมชันพับรูปลงโหลและคลี่ออก (3 ทบ, พลิกตัว, แสง, บิดฝา) และม้วนกระดาษโน้ตโยนลงโหล
js/sound.js         เสียงกริ๊ง, เสียงวูบ, เสียงแกร๊กของฝา (WebAudio ไม่มีไฟล์เสียง)
js/sun.js           คำนวณเวลาพระอาทิตย์ขึ้น-ตก และ golden hour, เดาเมืองจากเขตเวลา
js/sky.js           ดึง palette, ย่อรูป
js/story.js         สร้างรูปสตอรี่ 1080×1920 และแชร์/บันทึก
js/store.js         IndexedDB
server.js           static server สำหรับ dev
```

- **เฟส 4 (ต้องมีเซิร์ฟเวอร์):** โหลของขวัญ, ฟ้าเดียวกัน

# Kepfa · เก็บฟ้าใส่โหล

ต้นแบบเว็บแอป (mobile-first) สำหรับเก็บภาพท้องฟ้า: ถ่ายฟ้าแล้วแอปจะดึงสีของฟ้าออกมาเป็นชั้นสีไหลลงโหล หนึ่งเดือนต่อหนึ่งโหล ครบปีได้ชั้นวาง 12 โหลที่เป็นสีฟ้าของทั้งปี

## วิธีรัน

```bash
npm start
```

แล้วเปิด http://localhost:5173

- ไม่ต้องติดตั้ง dependency ใช้แค่ Node (`server.js` เป็น static server ตัวเล็ก)
- ทดสอบบนมือถือที่ต่อ Wi-Fi เดียวกัน: ใช้ที่อยู่ LAN ที่ server พิมพ์ออกมา (เช่น `http://192.168.1.20:5173`) ผ่าน http ธรรมดาเบราว์เซอร์จะไม่ให้เปิดกล้องในหน้าเว็บ แอปจะสลับเป็นปุ่ม "ถ่ายรูปฟ้า" ที่เปิดแอปกล้องของเครื่องแทน ถ้าอยากเห็นกล้องสดในแอป ต้อง deploy บน https (เช่น Vercel)
- เปิดครั้งแรกจะมีฟ้าตัวอย่างเติมไว้ในชั้นวาง กด "ล้างตัวอย่าง" เพื่อเริ่มเก็บฟ้าของตัวเอง

## ฟีเจอร์ในต้นแบบนี้

| ส่วน | ทำอะไรได้ |
|---|---|
| เก็บฟ้า | กล้องสด (หลังเครื่อง) หรือเลือกจากคลังภาพ → ดึง palette 3–5 สีด้วย k-means (ตัดแถบตึกด้านล่างภาพออก) → เดาประเภทฟ้าจากสีและเวลา → เขียนบันทึก (120 ตัวอักษร) แก้วันเวลาได้ |
| หย่อนลงโหล | ภาพหล่นลงโหล + เสียง "กริ๊ง" (WebAudio) + สั่น แล้วชั้นสีใหม่ไหลขึ้นมา |
| ชั้นวาง | 12 โหลต่อปี ชั้นล่าสุดอยู่บนสุด สลับปีได้ |
| โหลรายเดือน | แตะชั้นสีเพื่อเปิดฟ้าวันนั้น, "เขย่าโหล" สุ่มความทรงจำ, สถิติประจำเดือน |
| Sky dex | สะสมฟ้า 9 แบบ พร้อมคำใบ้ว่าจะไปหาฟ้าแบบที่ยังไม่เจอได้ที่ไหน |
| แชร์ลง IG Story | รูป 1080×1920 สามแบบ: ฟ้าเดี่ยว (โพลารอยด์ + palette), โหลรายเดือน, ชั้นวางทั้งปี + แถบสีทั้งปี มือถือใช้ share sheet ได้ตรง ๆ ส่วนเดสก์ท็อปจะบันทึกเป็นไฟล์ |
| ธีม | พื้นหลังเปลี่ยนตามช่วงเวลาจริง (เช้า/กลางวัน/เย็น/ค่ำ) และรองรับ dark mode |

ข้อมูลทั้งหมดเก็บในเครื่องด้วย IndexedDB ไม่มีบัญชีผู้ใช้และไม่มีเซิร์ฟเวอร์

## โครงสร้าง

```
index.html          โครงหน้า + overlay (กล้อง, รายละเอียด, แชร์)
css/style.css       design tokens, layout, dark mode
js/app.js           routing (#/, #/jar/YYYY-MM, #/dex), หน้าจอทั้งหมด, flow เก็บฟ้า, ข้อมูลตัวอย่าง
js/sky.js           ดึง palette, จัดประเภทฟ้า, ย่อรูป, วาดฟ้าตัวอย่าง
js/jar.js           วาดโหลแก้วและชั้นสีบน canvas (ใช้ร่วมกันทุกหน้า + ตอน export)
js/story.js         สร้างรูปสตอรี่ 1080×1920 และแชร์/บันทึก
js/store.js         IndexedDB
server.js           static server สำหรับ dev
```

## ไอเดียต่อจากนี้

- "ฟ้าเดียวกัน": แชร์โหลกับเพื่อนหรือแฟนที่อยู่ไกล (ต้องมี backend เช่น Supabase)
- แจ้งเตือน golden hour ตามพิกัด
- export คลิปตอนสีไหลลงโหลเป็นวิดีโอสำหรับ Reels/Story
- Sky Wrapped สิ้นปี
- service worker ให้เปิดแบบ offline และติดตั้งเป็นแอปได้เต็มรูปแบบ

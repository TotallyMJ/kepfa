# Kepfa · Keep the sky.

ต้นแบบเว็บแอป (mobile-first) สำหรับเก็บภาพท้องฟ้า ถ่ายฟ้าผ่านกรอบขวดยาโบราณ ปิดจุก แล้ววางขวดไว้บนชั้น หน้าตาแอปเป็นสไตล์ Kinfolk และใช้ภาษาอังกฤษ

ลองได้ที่ https://totallymj.github.io/kepfa/

## วิธีรันในเครื่อง

```bash
npm start
```

แล้วเปิด http://localhost:5173

- ไม่ต้องติดตั้ง dependency ใช้แค่ Node (`server.js` เป็น static server ตัวเล็ก)
- กล้องในหน้าเว็บต้องใช้ https หรือ localhost ถ้าเปิดผ่าน http บนมือถือ แอปจะสลับเป็นปุ่ม "Take a photo" ที่เปิดแอปกล้องของเครื่องแทน
- เปิดครั้งแรกจะมีฟ้าตัวอย่างวางไว้บนชั้น กด "Clear samples" เพื่อเริ่มเก็บฟ้าของตัวเอง

## ฟีเจอร์ (เฟส 1)

| ส่วน | ทำอะไรได้ |
|---|---|
| ขวด | ทุกที่ที่มีรูปจะอยู่ในขวดทรงเดียวกัน (ขณะถ่าย, ชั้นวาง, รายละเอียด, รูปแชร์) วาดจาก `bottleShape()` ที่เดียว |
| Keep a sky | จอกล้องมองผ่านขวด หรือเลือกรูปจากคลังภาพ → ดึง palette 3–5 สี → ใส่ Note และ Place (ไม่บังคับ) → "Cork it" แล้วจุกจะหล่นลงปิดขวด |
| Shelf (หน้าแรก) | หนึ่งขวดต่อหนึ่งฟ้า เรียงจากล่าสุด แบ่งตามเดือน ใต้ขวดมีวันที่และเวลา |
| Months | หนึ่งขวดต่อหนึ่งเดือน มีชั้นสีของทุกฟ้าในเดือนนั้น แตะเข้าไปดูสถิติ สีประจำเดือน "Shake" สุ่มความทรงจำ |
| Share to story | รูป 1080×1920 บนกระดาษ: ฟ้าเดี่ยว (ขวด + ตราประทับเดือน/วัน + วันที่-เวลา + palette), ขวดรายเดือน, ชั้นวางทั้งปี |
| ความเป็นส่วนตัว | ข้อมูลอยู่ในเครื่องเท่านั้น (IndexedDB) ไม่มีบัญชี ไม่มีเซิร์ฟเวอร์ ป้ายสถานที่ในรูปแชร์ปิดไว้เป็นค่าเริ่มต้นทุกครั้ง และรูปแชร์ถูกวาดใหม่ จึงไม่มีข้อมูล GPS ติดไป |

## โครงสร้าง

```
index.html          โครงหน้า + overlay (กล้อง, รายละเอียด, แชร์)
css/style.css       design tokens (Kinfolk), layout, dark mode
js/strings.js       ข้อความทั้งหมดในแอป + รูปแบบวันที่ (เพิ่มภาษาอื่นได้ที่ไฟล์นี้)
js/app.js           routing (#/, #/months, #/month/YYYY-MM), หน้าจอทั้งหมด, flow เก็บฟ้า, ข้อมูลตัวอย่าง
js/jar.js           ขวด: เรขาคณิต, SVG สำหรับหน้าจอ, canvas สำหรับรูปแชร์, ชั้นสีรายเดือน
js/sky.js           ดึง palette, ย่อรูป, วาดฟ้าตัวอย่าง
js/story.js         สร้างรูปสตอรี่ 1080×1920 และแชร์/บันทึก
js/store.js         IndexedDB
server.js           static server สำหรับ dev
```

## แผนถัดไป

- **เฟส 2:** ข้อความในขวด (จดหมายถึงตัวเองในอนาคต), แถบ golden hour, วันนี้ในอดีต, โจทย์ประจำสัปดาห์
- **เฟส 3:** หน้าสรุปเดือน / ปี
- **เฟส 4 (ต้องมีเซิร์ฟเวอร์):** ขวดของขวัญ, ฟ้าเดียวกัน
